# Tabby Server Panel

A plugin for [Tabby Terminal](https://github.com/Eugeny/tabby) that provides a three-layer bottom panel for SSH sessions:

1. **Server Stats** - Real-time CPU, RAM, SWAP, Disk, Network monitoring
2. **Quick Commands** - Customizable command buttons with tabbed pages
3. **File Manager** - SFTP-based file browser (coming soon)
